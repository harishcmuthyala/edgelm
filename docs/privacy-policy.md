# EdgeLM Privacy Policy

**Last updated: June 2026**

## Summary
EdgeLM does not collect, store, or transmit any personal data.

## Data Collection
EdgeLM collects no personal information. The app does not use
analytics, crash reporting, or any third-party tracking SDKs.

## Text Processing
All text you enter or select is processed entirely on your device
using a locally stored language model. No text is ever sent to
any server.

## Model Download
On first launch, the app downloads a model file (~1.1 GB) from
HuggingFace (huggingface.co). No personal data is transmitted
during this download. Only the model file is downloaded.

## Internet Permission
The INTERNET permission is used solely to download the model
file on first launch. After the model is downloaded the app
works entirely offline.

## Children's Privacy
EdgeLM does not knowingly collect data from anyone including
children under 13.
